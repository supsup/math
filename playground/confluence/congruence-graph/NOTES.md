# Finite congruence lattices: the graph criterion, checked by brute force

Lean: `lean/ComparatorChallenges/FiniteCongruenceGraph.lean` (statement, proof `sorry`), solution
`lean/OAI/Algebra/Universal/GraphCriterion.lean` + `Congruence.lean` (a 2-module, Mathlib-only cone).
Paper (context only): `preprints/Finite-Congruence-Lattices-Characterization-and-Undecidability-September-24-2026/`.

## What it says, in my words

Let `L` be a finite lattice. Then the following are equivalent:

- **A (Representable).** For some `n >= 1` there is an algebra on `{0..n-1}` (finitely many operations,
  each of finite arity, arity 0 allowed) whose set of congruences, ordered by inclusion, is
  order-isomorphic to `L`.
- **B (HasGraphWitness).** For some `n >= 1` there is a coloring `color(x, y) in L` of all ordered pairs
  of `{0..n-1}` such that
  1. `color(x, y) = color(y, x)`;
  2. `color(x, y) = ⊥` exactly when `x = y`;
  3. `color(x, y) <= color(x, z) ⊔ color(z, y)` (an `L`-valued ultrametric-style triangle law);
  4. whenever `a` is not `<= b`, some pair has color `<= a` and not `<= b` (equivalently: every element
     of `L` is the join of the colors below it);
  5. for every NONEMPTY finite set `S` of ordered pairs (seeds), every pair `(x, y)` with
     `color(x, y) <= ⊔_{s in S} color(s)` is linked to `x = y` in the equivalence relation generated by
     the images `(p a, p b)` of seeds `(a, b) in S` under "admissible" maps `p`, the self-maps with
     `color(p u, p v) <= color(u, v)` for all `u, v`.

This is NOT the open Finite Lattice Representation Problem (whether every finite lattice is
representable); it is a reformulation of representability. The theorem says nothing about which lattices
are representable.

## Method (enumerate.py, CongruenceGraph.java)

Both sides are existential over the size `n`, so I test the stronger SIZE-MATCHED statement
`A_n(L) <-> B_n(L)` for every lattice `L` with `|L| <= K` and every `n <= N`. If that holds for every
`n <= N`, the `n`-bounded version of the criterion holds too. (The Lean proof is in fact size-preserving
both ways: `principalColor` on the same carrier, `graphAlgebra` on the same carrier.)

- **Lattices.** All lattices on `k` elements, labeled along a linear extension, deduplicated by a
  canonical form (min order bit-string over relabelings fixing ⊥ and ⊤). Counts 1, 1, 1, 2, 5, 15, 53 for
  `k = 1..7` (the known sequence, OEIS A006966).
- **Side A from the definition.** Compatibility with an op of any arity equals compatibility with its
  one-variable translations, so the attainable families on `Fin n` are exactly intersections of the
  families `Con(f)`, `f : n -> n`, with the empty intersection (no operations) giving all equivalences.
  The closure is computed exhaustively: 1, 1, 8, 303, 39397 distinct families for `n = 1..5`. The
  reduction is itself tested: 300 random algebras per `n = 2, 3, 4` with arities 0..3, congruences
  computed straight from `Compatible`, all land in the computed family set.
- **Side B from the definition.** All symmetric colorings with ⊥ exactly on the diagonal (any witness
  has that shape), conjuncts checked one by one. Admissible maps are found by testing all `n^n` maps.
  Conjunct 5 is checked LITERALLY (all `2^(n^2) - 1` nonempty seed sets) for `n <= 3`; for `n = 4, 5` a
  fast equivalent is used: the condition depends on a seed set only through (join of its colors, union of
  its seeds' image sets), so I close the singletons under that pairwise union. Literal vs fast agreed on
  all 90 colorings compared (all 30 passing conjuncts 1-4 at `n <= 3`, 60 at `n = 4`), 69 true and 21
  false, so both outcomes were exercised.

## Negative control (the enumeration must be able to say "no")

Drop conjunct 5 (generation). Then B becomes true where A is false: 4 instances at `n = 4` among
lattices of size <= 6 (all 6-element), 12 among size <= 7 (K7 run). Explicit one: `L = M4` (⊥, four pairwise incomparable atoms 1..4, ⊤ = 5), `n = 4`,

```
color = [[0,1,1,2],
         [1,0,1,3],
         [1,1,0,4],
         [2,3,4,0]]
```

Conjuncts 1-4 hold. Conjunct 5 fails at the single seed `(0,1)`: its color is atom 1, the pair `(0,2)`
also has color 1, but only 5 maps are admissible and their images of `(0,1)` do not connect 0 to 2. And
M4 is not the congruence lattice of any algebra on 4 points: none of the 303 congruence families on
`Fin 4` is isomorphic to it (measured by the enumeration, not argued).

Also (K6 run; K7 run in brackets): dropping conjunct 4 gives 79 [287] disagreements (from `n = 1`: a single point with the zero coloring
"witnesses" any lattice), dropping conjunct 3 gives 16 [55] (first at `n = 3`, e.g. the 4-chain). So each of
conjuncts 3, 4, 5 is load-bearing in the enumerated range. (Conjuncts 1 and 2 were not controlled: the
enumeration builds them into the coloring shape.)

## LIMITS

- The theorem is unbounded in `n`; I check only `n <= 4` for `|L| <= 7`, `n <= 5` for `|L| <= 5`. That is
  evidence for the size-matched statement, not a proof. The Lean build is the proof.
- Side A relies on the translation reduction (a short, standard argument, and the solution proves it as
  `compatible_iff_translations`). I tested it on 900 random algebras, not exhaustively over all algebras.
- Conjunct 5 for `n >= 4` uses the closure shortcut; it was cross-checked against the literal definition
  on 60 colorings at `n = 4`, not on all.
- The criterion does not decide representability; nothing here bears on the open Finite Lattice
  Representation Problem, or on the paper's undecidability claims, which I did not check.
- I did not run the official Comparator tool; `statement_match.py` is a textual comparison.
