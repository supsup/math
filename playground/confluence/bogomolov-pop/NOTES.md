## Docs Scope (quoted)

> The linked formalization proves injectivity of the reconstruction correspondence for function
> fields of transcendence degree at least two over algebraically closed fields of characteristic
> different from the prime $\ell$.
>
> If two isomorphisms of perfect closures preserving the constant fields induce the same
> Galois-data isomorphism modulo $\ell$-adic unit scaling, then they agree modulo Frobenius. The
> selected statement proves this uniqueness; existence of a field isomorphism for every admissible
> Galois-data isomorphism is outside it.

So the docs themselves say the formal statement is the uniqueness (injectivity) half only, not
the reconstruction theorem.

## The statement in plain words

For a prime ell, algebraically closed k, l with char != ell, and fields K|k, L|l essentially of
finite type with trdeg >= 2:

- `PerfectIsom k K l L`: ring isomorphisms K^perf -> L^perf (perfect closures inside the
  algebraic closures) that map the image of k onto the image of l.
- `IsomF`: those modulo the equivalence generated by `FrobeniusStep` (beta = alpha^p pointwise,
  p = char L prime). In characteristic 0 there is no step, so IsomF is plain equality.
- `ProEll F` = G_F / (intersection of open normal H with G_F/H an ell-group): maximal pro-ell
  quotient. `PiA` = its topological abelianization, `PiC` = quotient by the closure of
  [closure([G,G]), G], `Delta` = ker(PiC -> PiA), `bracket` = commutator of lifts.
- `IsomC ell K L`: topological group isomorphisms phi : PiA L -> PiA K for which some
  topological isomorphism psi : Delta L -> Delta K satisfies psi[s,t] = [phi s, phi t].
- `IsomCUnits`: IsomC modulo the equivalence generated by phi ~ phi^u, u in Z_ell^x (defined as a
  limit of phi(x)^(appr u n)).
- `PullbackGraph alpha phi`: some extension beta : Kbar -> Lbar of alpha has, for every
  sigma in G_L, a tau in G_K with beta tau = sigma beta and phi(image sigma) = image tau. That is,
  phi is the map on abelianized pro-ell Galois groups induced by alpha.
- `PhiGraph a b`: some representatives of a and b satisfy PullbackGraph.

Theorem: `PhiGraph a b -> PhiGraph a' b -> a = a'`. Two isomorphisms of perfect closures that
induce the same abelian pro-ell Galois isomorphism up to an ell-adic unit agree up to Frobenius
twists.

## Audit verdict

Faithful to the docs Scope, and the Scope is honest that it is the uniqueness half.

Things checked:

- **Not vacuous.** The solution proves `main_wellDefined`: every `a : IsomF` has exactly one `b`
  with `PhiGraph a b` (via `exists_pullbackGraph`, no hypotheses). So the relation is a total
  function and the theorem is injectivity of that function. It has content whenever IsomF has
  two or more elements, e.g. K = L = k(x,y) with the swap x <-> y. That last example is my
  reasoning; Lean does not check it.
- **Quotient directions are the hard ones.** A coarser relation on IsomCUnits would make the
  theorem STRONGER (more pairs share a b). A coarser relation on IsomF would make it weaker, but
  that relation is only Frobenius twisting, which is exactly the known ambiguity, and is equality
  in characteristic 0.
- **The topology is Krull.** The solution rewrites with `krullTopology_mem_nhds_one_iff` on
  neighbourhoods in `Field.absoluteGaloisGroup` (Foundations.lean:230 and 282,
  Canonical.lean:494), which typechecks only against the Krull topology. So `ProEll` is the real
  maximal pro-ell quotient and is not a discrete-topology artefact.
- **No division, sSup or sInf tricks.** `Quotient.out` in `bracket` picks a fixed lift, so
  `bracket` is a function whatever happens. Bracket compatibility only narrows IsomC, and the
  induced maps are shown to satisfy it (`induced_bracketCompatible`).
- **The hypotheses are stronger than the proof uses.** `main_canonical_injective` uses
  `hk : (ell:k) != 0` and gets one transcendental element from `hK`, so it only needs
  trdeg >= 1. `hl` and `hL` are `_`-prefixed (unused). That fits the literature as I recall it:
  injectivity is the elementary half, from Kummer theory plus Frobenius rigidity, and trdeg >= 2
  is needed for existence/surjectivity. This does not weaken the statement.
- **Literature (recalled, not re-verified here).** Bogomolov's program; Bogomolov–Tschinkel
  proved reconstruction for function fields over the algebraic closure of a finite field. Pop
  (Invent. Math. 2012, "On the birational anabelian program initiated by Bogomolov I") proved
  that Isom^i(perfect closures)/Frobenius -> Isom^c(Pi^c)/Z_ell^x is a bijection for trdeg >= 2
  over algebraically closed k, char != ell. The formal statement is the injective half of that
  map.

## Finite checks (`toy_check.py`, Java `confluence.math.bogomolov.BogomolovPop`)

The real objects are infinite (absolute Galois groups), so nothing checks the theorem directly.
Two finite pieces of the mechanism:

- **Check A** (the Lean lemma `polynomial_power_prime`): (X+1)^n = X^n+1 in k[X] iff n = 1 or
  n = p^r with p = char k. Tested by brute force for char in {0,2,3,5,7,11,13} and n <= 300:
  0 mismatches (Python and Java).
- **Check B** (a toy I constructed; it is not in the paper): K = F_q(x), maps in PGammaL2(F_q)
  (constants mapped onto constants), Kummer data restricted to V = sum-zero vectors in
  (Z/ell)^{P^1(F_q)}, which is exactly <x - t> modulo constants and ell-th powers. Invariant:
  the action on V modulo F_ell^x. Injective on all of PGammaL2 for q in {2,3,5,7,4,9,8} with
  several ell != p (Python, which covers prime powers; group sizes 6 to 1512), and for prime
  q <= 11 (Java). The absolute Frobenius f -> f^p acts on V as the scalar p. For example
  (q,ell) = (5,3) gives different raw matrices that are equal modulo scalars. This is why the
  Galois side is taken modulo units.
- **Control C1 (must fail; it does):** the rank-one piece span(e_0 - e_inf). x -> 1/x and
  x -> 1/(2x) (q=5, ell=3) give the same data. On F_4, x -> 1/x and its Galois twist collide
  too.
- **Control C2 (must fail; it does):** the sign of the action gives 2 classes and collides
  everywhere.
- **Mutant instrument (must lose injectivity; it does):** dropping the Galois twist from the point
  action gives 60, 720 and 504 classes for 120, 1440 and 1512 maps (q = 4, 9, 8). A Java mutant
  that sets the point map to the identity whenever c = 0 makes Check B report
  `injective=false` (101 classes for 120 maps at q=5), so the checker can detect a wrong action.

## LIMITS

- The toy is mine. K has a finite constant field (the theorem needs an algebraically closed
  one), it is a rational function field of trdeg 1, and the Galois data is cut down to a finite
  Kummer piece mod ell. It shows how "map -> induced Kummer action mod scalars" separates
  automorphisms. It is not evidence for the theorem; the evidence is the Lean build.
- I did not read the full 3,339 lines of the proof. I relied on the kernel check, the axioms list
  and statement_match. I read the top-level chain: `main_graph_injective` ->
  `main_canonical_injective` -> `pullback_scalar_frobenius` / `kummer_endomorphism_frobenius` ->
  `integer_power_endomorphism_rigid`.
- I did not open Mathlib's source to confirm the topology instance. The Krull-topology
  conclusion comes from the solution typechecking with `krullTopology_mem_nhds_one_iff`.
- The literature attribution (Pop 2012, Bogomolov–Tschinkel) is from memory and was not
  re-checked against the papers. I did not read the preprint PDF.
- I did not check that the docs PDF's main theorem uses the same ambiguity groups. I compared
  only the docs Scope text to the Lean.
