# Independent audit of the proposed uniform odd-small-leaf switch

**Scope.** This note checks the construction for odd `t=2lambda+1>=3` and odd `p>=t`. It is an independent derivation from the stated cyclic walk and row rule, plus an independently written finite edge replay. It does not address the large-leaf range `t>p` or publication priority.

At each odd-degree hub at least one incident edge must be a singleton. If `s>=p` singleton edges occur, the cycles cover `pt-s` edges, each simple cycle using at most `2t` edges. Thus the part count is at least `s+ceil((pt-s)/(2t))`, which is nondecreasing in integer `s`; at `s=p` it is `p+ceil(p*lambda/t)`. Therefore a partition with exactly `p` singletons and `ceil(p*lambda/t)` cycles proves equality.

The `r=0` seed `p=t` has the standard modular square block: one singleton `(h,h)` for each hub; for shifts `a=1,3,...,t-2`, the two consecutive difference matchings `a,a+1` form one Hamilton cycle on the `t` hubs and `t` leaves. Each nonzero difference occurs once, so this gives `lambda` cycles and all `t^2` edges exactly once.

For a seed `p=t+2r`, `1<=r<t`, put `n=lambda+r`, `q=2n=p-1`, `m=t-1=2lambda`, and add one new leaf `z=m` and one new hub `u=q` to the old `q` hubs and `m` active leaves. The even weave cycles are indexed by `j=0,...,n-1`; cycle `j` has hub sequence `H_(j,k)=2j+k mod q` and leaf sequence `L_k=k` for `k=0,...,m-1`. Its `m` hubs are distinct since `m<q`. At each leaf `k<m-1`, its two hub neighbors in cycle `j` are `2j+k` and `2j+k+1`; as `j` varies they run through opposite parity classes and cover all `q` hubs once. At leaf `m-1`, the neighbors are `2j+m-1` and `2j`, again opposite parity classes. Thus the `n` cycles partition `K_(q,m)`.

The key row assignment chooses one distinct row `j` for each column pair `s=0,...,lambda-1`, with the residues `j+s mod n` distinct. If `n` is odd, choose `j=s`: the sums `2s` are distinct modulo odd `n`. If `n=2a` is even, define `sigma(j)=(j+a-1) mod (n-1)` for rows `j=0,...,n-2`. Its values are exactly the columns `0,...,n-2`, which include all `s<lambda` because `r>=1`. Its sums `j+sigma(j)` are, for `j=0,...,a-1`, the odd/even-step list `a-1,a+1,...,3a-3`, and for `j=a,...,2a-2`, the interleaving list `a,a+2,...,3a-4`. Their union is the integer interval `a-1,...,3a-3` of length `n-1`, so these residues are distinct modulo `n`. Use the inverse row of `sigma` for each required `s`.

In each selected row `j` with column pair `s`, delete the two old cycle spokes `(H_(j,2s),2s)` and `(H_(j,2s+1),2s+1)`. Replace them by `(H_(j,2s),z)`, `(H_(j,2s+1),z)`, `(u,2s)`, `(u,2s+1)`. Because the two deleted edges are distinct and lie on the same simple cycle, cutting them creates two paths; connecting the two old-hub endpoints through `z` and the two old-leaf endpoints through `u` joins those paths into **one** simple cycle. It gains two vertices and four edges net of the two removed edges, so its length becomes `2(m+1)=2t`. Unselected cycles remain simple `2m=2(t-1)` cycles. The selected old hubs have residues `2(j+s)` and `2(j+s)+1` modulo `2n`, so the distinct-sum rule makes all `2lambda=m` selected hubs distinct. The selected columns cover all active leaves exactly once.

Make each deleted old spoke a singleton. For each selected old hub, its `(h,z)` edge has entered a cycle; for every unselected old hub, retain `(h,z)` as its singleton. Make `(u,z)` a singleton. Thus every old hub and `u` has exactly one singleton. Every old-active edge either stayed in its original cycle or became a singleton; each old-`z` edge is in a cycle or singleton; each `u`-active edge occurs once because its column was selected once; `(u,z)` occurs once. This is an exact partition of all `pt` edges. It has `lambda` full cycles and `r` short cycles, hence `lambda+r` cycles. Since `p=t+2r` and `r<t`, `ceil(p*lambda/t)=lambda+ceil(r-r/t)=lambda+r`.

Finally, every odd `p>=t` has a unique expression `p=t+2r+2tm` with `0<=r<t`, `m>=0`. Put the seed on one hub set and `2m` copies of the `t`-hub square block on disjoint hub sets sharing the same leaves. The resulting cycle count is `lambda+r+2m*lambda=ceil(p*lambda/t)` and singleton count is `p`; disjoint hub sets make all edges disjoint. This proves the formula at every odd `p>=t` once the seed construction is accepted.

The [independent replay](odd_all_leaves_uniform_independent_replay.py) builds literal undirected bipartite graphs and checks singleton count, edge multiplicity, every cycle's degree-two connectivity and vertex simplicity, full/short cycle lengths, and sharp count for all 2,550 seeds with odd `t=3..101` and every `1<=r<t`. It reports PASS. This finite test is a transcription check; the proof above supplies the unbounded result.
