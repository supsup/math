# Every large leaf count with twenty-seven bipartite hubs

The next composite odd hub count meets the same exact formula. If `d(G)` is the minimum number of simple cycles and singleton edges partitioning `E(G)`, then

> **`d(K_{27,t})=t+ceil(13t/27)` for every `t≥26`.**

This is a fixed-hub theorem from fourteen even-base weaves, one offset base, twelve saved odd-base edge certificates, and a residue lift. It does not establish a uniform composite-hub construction or the all-odd-hub conjecture. Publication priority is unverified.

**Lower bound.** Every leaf has odd degree 27, so at least one of its spokes is a singleton part. Let there be `s=t+X` singleton spokes. The cycles then use `13t−X/2` leaf appearances, at most 27 in any simple cycle. Consequently `r+s≥t+13t/27+(53/54)X`, and `d(K_{27,t})≥t+ceil(13t/27)`. Here `X` is a nonnegative even integer because each leaf has an odd singleton-spoke count. If `X≥2`, the real lower bound increases by `53/27>1`, so a partition meeting the displayed bound has exactly one singleton at each leaf. This parity/capacity lower-bound mechanism for `K_{2k+1,t}` appears in [Bucić–Montgomery, Section 6](https://rhmontgomery.warwick.ac.uk/papers/28cyclepacking.pdf) as the Erdős/Gallai extremal example; the exact fixed-hub upper construction is the subject here.

**All 27 base residues.** For even `b=26,28,…,52`, declare hub 26's `b` spokes singleton and use the [even-side weave](30_even_hub_cycle_weave.md) to partition the residual `K_{26,b}` into `b/2` simple 52-edge cycles. On this interval `ceil(13b/27)=b/2`. At `b=27`, use 27 diagonal singleton spokes and thirteen 54-edge [offset cycles](10_odd_hub_blocks.md). The twelve odd bases `b=29,31,…,51` use the saved [JSON walks](40_twentyseven_hub_odd_seeds.json). For `b=27+2j`, `1≤j≤12`, there are thirteen full 54-edge cycles and `j` short 52-edge cycles, giving `b+13+j=b+ceil(13b/27)` parts. The singleton degrees are three at hubs `0,…,j−1` and one elsewhere; each short cycle omits one triple-spoke hub. The omitted leaves obey the [cyclic interval schedule](33_interval_omission_schedule.md), while the saved edge assignments ensure that every proposed cycle is connected and simple.

The [checker](40_twentyseven_hub_all_residues.py) reconstructs every base partition, checks each spoke exactly once, checks cycle simplicity and interval omissions, verifies eleven lifted copies per base, and draws the [residue ladder](art/twentyseven_hub_residue_ladder.svg). A separate verifier checked connectedness and edge coverage directly from the solver's raw edge lists, and I rebuilt all twelve saved walks without importing either checker. The JSON SHA-256 is `51084fdc740ec9e27fdb68b7126a5a8ff13892b39afceccaf4069e15f93bbc1c`. The CP-SAT searches for the twelve bases took 0.40–1.45 seconds each; the walks show no simple algebraic edge rule yet.

**Lift.** Every `t≥26` is uniquely `b+27q` for `26≤b≤52`, `q≥0`. Appending one disjoint 27-leaf offset block adds 27 singleton spokes and thirteen Hamilton cycles, or 40 parts. The bound `t+ceil(13t/27)` also rises by 40 when `t→t+27`, so every residue is exact. [Item 42](42_twentynine_affine_growth.md) covers prime `h=29≡1 (mod 4)` by a different growth page. The next unverified odd hub count is composite `h=33`.
